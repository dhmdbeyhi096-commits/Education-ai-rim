# مساعد الذكاء الاصطناعي التعليمي

هذا المشروع يهدف إلى توفير مساعد تعليمي ذكي للطلاب الموريتانيين. يهدف إلى تحسين تجربتهم التعليمية من خلال تزويدهم بمعلومات موثوقة وسريعة في مختلف المواد الدراسية.

## ميزات المشروع:
- **تقديم المساعدة في الواجبات المنزلية:** يساعد الطلاب في حل المشكلات الأكاديمية.
- **موارد تعليمية:** يوفر موارد مثل المقالات، الفيديوهات، والتمارين.
- **دعم اللغتين:** يدعم اللغة العربية والفرنسية لتحسين الوصول.

## كيفية الاستخدام
1. قم بتسجيل الدخول.
2. اختر الموضوع الذي ترغب في المساعدة فيه.
3. اتبع التعليمات المقدمة من المساعد الذكي.

هذا المشروع يمثل خطوة نحو تحسين التعليم في موريتانيا ويعكس التقدم التكنولوجي في مجال التعليم.
